# AI Context - Tizino

این فایل قوانین همکاری بین توسعه‌دهنده و دستیار هوش مصنوعی (Claude / ChatGPT) را مشخص می‌کند.

---

# نسخه‌های پروژه

- Laravel 13.23.0
- PHP ^8.3
- Filament 5.7.4
- Livewire 4.3.3
- MySQL
- spatie/laravel-permission 8.3.0

برنچ فعال: `rescue-filament`

محیط توسعه: Windows + Laragon، روی دو سیستم (خانه و محل‌کار).

---

# قوانین توسعه

- همیشه از API رسمی Filament 5.7.4 استفاده شود.
- هیچ نمونه کدی از Filament 3 یا 4 استفاده نشود.
- قبل از ارائه کد، ساختار فعلی پروژه بررسی شود.
- اگر ساختار پروژه با نسخه‌های قدیمی تفاوت دارد، نسخه فعلی ملاک باشد.
- هر Resource باید مستقیم زیر `app/Filament/Resources/` باشد.
- کلاس `Get` از `Filament\Schemas\Components\Utilities\Get` import شود (نه `Filament\Forms\Get`).
- `Section` از `Filament\Schemas\Components\Section` import شود.
- مدل `User` از PHP Attributes (`#[Fillable(...)]`, `#[Hidden(...)]`) استفاده می‌کند؛ فیلد جدید باید به همان Attribute اضافه شود.
- ستون نام `Grade` در دیتابیس `title` است، نه `name`.

---

# نحوه ارائه کد

- همیشه فایل کامل ارسال شود.
- فقط بخشی از فایل (یا diff) ارسال نشود.
- فایل‌ها به‌صورت attachment ارسال شوند و مسیر دقیق جایگزینی بالای هر فایل نوشته شود.
- نام فایل ارسالی دقیقاً همان نام نهایی مورد انتظار پروژه باشد (مثلاً `dashboard.blade.php`، نه `dashboard_v2.blade.php`).
- توضیحات کوتاه و کاربردی باشند.
- مراحل به‌صورت متن ساده‌ی شماره‌دار نوشته شود و کد داخل بلاک قابل کپی باشد.
- ابتدا طراحی، سپس کدنویسی.
- در صورت نیاز، Migration → Model → Resource → Logic رعایت شود.
- هر جلسه یک فیچر اصلی؛ در پایان داک‌ها هم‌گام شوند.

# زبان پروژه

- پنل مدیریت فارسی
- نام کلاس‌ها انگلیسی
- نام جدول‌ها انگلیسی
- نام ستون‌ها انگلیسی
- کامنت‌های غیرضروری نوشته نشوند.
- تمام تاریخ‌های سراسر سایت (نمایش و ورودی) باید شمسی باشند (کاربران ایرانی‌اند)؛ ذخیره‌سازی در دیتابیس میلادی می‌ماند. از `app/Support/JalaliDate.php` (نمایش) و `app/Filament/Forms/Components/JalaliDateTimePicker.php` (ورودی فرم) استفاده شود؛ به هیچ پکیج خارجی تقویم جلالی متکی نشوید (Packagist روی سیستم توسعه فیلتر است).
- تمام اعدادی که در پنل دانش‌آموز **و پنل ادمین** نمایش داده می‌شن باید با ارقام فارسی باشن (از `JalaliDate::toPersianDigits()` استفاده شود؛ برای مواردی که سمت کلاینت با جاوااسکریپت ساخته می‌شن، تابع تبدیل معادل جاوااسکریپتی لازمه).
