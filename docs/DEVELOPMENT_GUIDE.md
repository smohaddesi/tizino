# AI Context - Tizino

این فایل قوانین همکاری بین توسعه‌دهنده و ChatGPT را مشخص می‌کند.

---

# نسخه‌های پروژه

- Laravel 12
- PHP 8.4
- Filament 5
- Livewire 3
- MySQL

---

# قوانین توسعه

- همیشه از API رسمی Filament 5 استفاده شود.
- هیچ نمونه کدی از Filament 3 یا 4 استفاده نشود.
- قبل از ارائه کد، ساختار فعلی پروژه بررسی شود.
- اگر ساختار پروژه با نسخه‌های قدیمی تفاوت دارد، نسخه فعلی ملاک باشد.

---

# نحوه ارائه کد

- همیشه فایل کامل ارسال شود.
- فقط بخشی از فایل ارسال نشود.
- توضیحات کوتاه و کاربردی باشند.
- ابتدا طراحی، سپس کدنویسی.
- در صورت نیاز، Migration → Model → Resource → Logic رعایت شود.

---

# زبان پروژه

- پنل مدیریت فارسی
- نام کلاس‌ها انگلیسی
- نام جدول‌ها انگلیسی
- نام ستون‌ها انگلیسی
- کامنت‌های غیرضروری نوشته نشوند.

---

# معماری

- کدها قابل توسعه باشند.
- از قابلیت‌های خود Laravel و Filament استفاده شود.
- از ایجاد کد تکراری جلوگیری شود.
- تغییرات با ساختار فعلی پروژه سازگار باشند.

---

# قوانین پاسخ ChatGPT

- قبل از پیشنهاد تغییر، فایل فعلی بررسی شود.
- اگر نسخه کتابخانه مشخص است، همان نسخه ملاک قرار گیرد.
- از حدس زدن ساختار فایل‌ها خودداری شود.
- در صورت نیاز، فایل فعلی از کاربر دریافت شود.
- اگر در مورد نسخه یا ساختار پروژه ابهامی وجود دارد، ابتدا سؤال پرسیده شود.
