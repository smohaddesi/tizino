# Tizino - Project Rules

## Tech Stack

- Laravel 13.23.0
- PHP ^8.3
- Filament 5.7.4
- Livewire 4.3.3
- MySQL
- spatie/laravel-permission 8.3.0

برنچ فعال: `rescue-filament`

---

## General Rules

- تمام کدها بر اساس Filament 5.7.4 نوشته شوند.
- هیچ کد مربوط به Filament 3 یا 4 استفاده نشود.
- همیشه نسخه کامل فایل ارسال شود.
- هیچ‌وقت فقط بخشی از فایل ارسال نشود.
- متن‌های پنل مدیریت فارسی باشند.
- نام کلاس‌ها، جدول‌ها و ستون‌ها انگلیسی باشند.
- معماری پروژه قابل توسعه باشد.
- قبل از ایجاد هر Feature جدید، ساختار دیتابیس بررسی شود.
- تا حد امکان از قابلیت‌های خود Laravel و Filament استفاده شود.
- از ایجاد کد تکراری خودداری شود.
- تمام تاریخ‌های نمایش‌داده‌شده یا دریافت‌شده در سراسر سایت (پنل مدیریت و صفحات دانش‌آموزی) باید شمسی باشند؛ چون کاربران سامانه ایرانی‌اند. ذخیره‌سازی در دیتابیس همچنان میلادی می‌ماند، تبدیل فقط در لایه‌ی نمایش/فرم انجام می‌شود (`app/Support/JalaliDate.php` و `app/Filament/Forms/Components/JalaliDateTimePicker.php`).
- تمام اعدادی که در پنل دانش‌آموز **و پنل ادمین** نمایش داده می‌شن (نمره، تعداد، قیمت، شماره‌ی صفحه، تایمر و ...) باید با ارقام فارسی باشن؛ با `JalaliDate::toPersianDigits()` (سمت سرور) یا تابع جاوااسکریپت معادلش (برای مواردی مثل تایمر که سمت کلاینت ساخته می‌شن). این شامل View مشترک pagination خود Filament هم می‌شه (`resources/views/vendor/filament/components/pagination/`).
- هر Resource باید مستقیم زیر `app/Filament/Resources/` باشد.
- از نصب پکیج‌هایی که نیاز به Packagist دارند تا حد امکان پرهیز شود (Packagist روی سیستم توسعه فیلتر است)؛ راه‌حل داخلی ترجیح دارد.
- فایل‌ها به‌صورت attachment و با نام نهایی دقیق (بدون پسوند v2 و مشابه) ارسال شوند و مسیر جایگزینی ذکر شود.

## Development Style

- ابتدا طراحی
- سپس Migration
- سپس Model
- سپس Filament Resource
- سپس Business Logic
- سپس تست
- هر جلسه یک فیچر اصلی؛ در پایان داک‌ها (`docs/`) با کد واقعی هم‌گام شوند.

---

## Git

Commitهای کوچک و مشخص ایجاد شوند.

---

## Package Versions

قبل از تغییر ساختار یا API هر کتابخانه:

- ابتدا نسخه نصب‌شده بررسی شود.
- سپس کد بر اساس همان نسخه نوشته شود.
- از حدس زدن API نسخه‌ها خودداری شود.

- Always send complete files when modifying code.
- Follow Filament v5.7.4 conventions.
